Reference: `du-an/video-20-v3/scenes/HookComparison.tsx`; spec in `.agent/workflows/make-video.md` step 0a.

**How to apply:** draft the hook from the script and get approval before voicing (credits). Never invent statistics; flag the source for the user to verify. Skip only if the user says no hook. Related: [[narrator-voice-masane]], [[ask-before-render]].
